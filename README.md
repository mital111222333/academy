## 1. Публикация на GitHub Pages

1. Загрузите **все файлы и папки** из этой папки в репозиторий (`index.html` должен лежать в корне).
2. На GitHub откройте Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Без Supabase сайт работает в **локальном режиме**: прогресс хранится только в браузере агента, руководитель его не видит.

## 2. Подключение Supabase (прогресс агентов и панель руководителя)

1. Создайте бесплатный проект на https://supabase.com.
2. **SQL Editor** → New query → вставьте весь файл `supabase/schema.sql` → **Run**.
3. **Authentication → Providers → Email**: выключите **Confirm email**. Агенты входят по номеру телефона, технический e-mail вида `998901234567@mital.academy` создаётся автоматически, письма никуда не отправляются.
4. **Project Settings → API**: скопируйте `Project URL` и `anon public` ключ в `assets/js/config.js`:
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJ...",
   ```
   Ключ `anon` можно публиковать: доступ к данным защищён правилами RLS из `schema.sql`.
5. Зарегистрируйтесь на сайте своим номером, затем в SQL Editor выполните:
   ```sql
   update public.profiles set role = 'admin' where phone = '998XXXXXXXXX';
   ```
   После повторного входа появится раздел **Rahbar**.

## 3. Редактирование прямо на сайте (для руководителя)

Войдите под своим номером (с ролью `admin`) и нажмите вверху **✏️ Tahrirlash**. На каждой странице появятся жёлтые панели с кнопками:

| Где | Что можно |
|---|---|
| Главная | тексты главной страницы, картинка справа, структура курса, настройки |
| Mening yo‘lim | недели, модули (добавить / переставить / удалить), уровни SJ→SQ, экзамен |
| Страница модуля | название, описание, неделя, результаты; добавить, удалить или переставить уроки |
| Страница урока | всё содержимое урока: текст, заголовки, списки, **картинки**, **видео YouTube**, **ссылки-кнопки**, таблицы, диалоги, инфографика, задания, выводы и тест |
| Каталог | новый продукт, правка или удаление (вместе с фото), бренды, категории, порядок |
| Скрипты / Тренажёр / Экзамен / Компания | любые тексты, вопросы, ответы, порядок |

**Как это работает:**
- Блоки урока переставляются кнопками ↑ ↓, ⧉ делает копию, ✕ удаляет.
- Фото загружаются кнопкой **📷 Rasm yuklash**. С Supabase они хранятся в облаке и видны всем, в локальном режиме — только в этом браузере.
- **Rahbar → Kontent va tarix**:
  - быстрый доступ ко всем редакторам;
  - **история изменений**: любую версию можно восстановить;
  - **резервная копия**: скачать всё содержимое в JSON и восстановить из файла;
  - **возврат к исходному варианту** из файлов.
- С подключённым Supabase правки сразу видны всем агентам. Без Supabase они сохраняются только в вашем браузере.

Файлы в папке `content/` — это исходный вариант курса. Править их не обязательно: всё, что вы меняете на сайте, хранится отдельно и имеет приоритет.

**Видео к уроку:** ✏️ на странице урока → поле «Asosiy video» (или Rahbar → Videolar). Поддерживаются ссылки `youtu.be/…`, `youtube.com/watch?v=…`, `/shorts/…`, `/embed/…`.

После правки **файлов** замените в `index.html` все `?v=13` на `?v=14`, чтобы браузеры не показывали старую версию. При правках через сайт этого делать не нужно.

## Ограничения

- Ответы тестов хранятся в коде страницы. Технически подкованный агент может их найти. Для внутреннего обучения это допустимо. Для строгой аттестации вопросы нужно перенести в Supabase.
- Письма для сброса пароля не работают (адреса технические). Новый пароль агенту руководитель задаёт в SQL Editor, прогресс при этом сохраняется:
  ```sql
  update auth.users
  set encrypted_password = extensions.crypt('НовыйПароль123', extensions.gen_salt('bf'))
  where email = '998XXXXXXXXX@mital.academy';
  ```
